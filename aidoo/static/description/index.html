Aidoo — your AI assistant inside Odoo

Run AI workflows, see your assistant's history and connect Claude — all from a single button in the Odoo systray.

What it does

Aidoo button in the systray

A discreet Aidoo icon appears at the top right of every Odoo page — only for users whose email is linked to your Aidoo workspace. One click opens the panel.

Context-aware

Open the Aidoo panel from a sales order, an invoice or a contact and see the workflows compatible with that record highlighted, plus the last AI executions linked to it.

Features

  • Recent executions — see what your AI assistant ran for you, prioritising the current record.
  • Run workflows — launch Aidoo workflows from Odoo with a dynamic form generated from each workflow's variables.
  • One-click Claude — open Claude.ai from the panel and start a new chat connected to your Odoo.
  • Custom-connector helper — when Claude is not yet connected, the panel shows the Name and the MCP URL with copy buttons.
  • Multi-environment — separate connection keys for Production and Pre-production.
  • Secure — connection key encrypted with Fernet (AES-128-CBC + HMAC) and bound to your Odoo database.secret.
  • Multi-language — UI ships with French, Spanish and English. Pick the language from Settings → Aidoo.

Setup

  1. Install the Aidoo module from the Apps menu.
  2. Create your Aidoo account at app.aidoo.fr (free trial).
  3. On the Aidoo dashboard, go to Settings → Odoo module and generate a connection key for Production (or Pre-production).
  4. In Odoo, open Settings → Aidoo, paste the key and save.
  5. Click the Aidoo icon in the systray — you are connected.

Privacy & data

The module never sends Odoo data to a third party on its own. It only calls the Aidoo backend you registered, using a key encrypted on disk with your Odoo database.secret. A user can only see the Aidoo panel if their Odoo email matches an Aidoo workspace member of your own organisation — strict per-company scoping.

Requires

An Aidoo account at app.aidoo.fr.
Python dependency installed automatically by Odoo: cryptography.
