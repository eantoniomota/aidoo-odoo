Aidoo for Odoo

Bring the Aidoo AI assistant inside Odoo. Run AI workflows, see recent executions, and act on the current record — all from a single button in the Odoo systray.

Features

  • Systray icon — discreet Aidoo button at the top right of every Odoo page.
  • Recent executions — see what your AI assistant did, prioritising the current record.
  • Run workflows — launch Aidoo workflows with a dynamic form for variables.
  • Context-aware — workflows compatible with the current model are highlighted.
  • Secure — API key encrypted with Fernet (AES-128-CBC + HMAC) and bound to your Odoo database secret.
  • Multi-version — separate branches for Odoo 17, 18 and 19.

Setup

  1. Install the Aidoo module from the Apps menu.
  2. Go to Settings → General Settings → Aidoo and connect to your Aidoo workspace.
  3. Users that already exist in your Aidoo workspace (matched by email) immediately see the systray icon.

Requires

An Aidoo account at app.aidoo.fr.
Python dependency: cryptography.
